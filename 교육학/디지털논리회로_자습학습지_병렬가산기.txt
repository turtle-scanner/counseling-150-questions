1. 병렬 가산기(Parallel Adder)의 개념
  - 2개 이상의 여러 비트(n-bit)로 구성된 2진수를 [             ]으로 동시에 더하여 합(Sum)과 올림수(Carry)를 구하는 회로이다.

2. 병렬 가산기의 내부 회로 구성
  - 1비트 2진수 2개와 하위 올림수를 더하는 [                ](Full Adder, FA)를 여러 개 직렬 연결하여 구성한다.
  - 4비트 2진수 2개를 동시에 더하기 위해서는 전가산기(FA)가 총 [       ]개 필요하다.

3. 올림수(Carry)의 전달 과정 (Ripple Carry 방식)
  - 최하위 비트(FA0)에서 발생한 올림수 [  C₁  ]은 다음 자리인 [  FA₁  ]의 올림수 입력으로 전달된다.
  - 이처럼 하위 비트의 올림수가 상위 비트로 물결(Ripple)치듯 차례대로 전달되는 방식을 리플 캐리 가산기라고 한다.

4. 대표적인 상용 4비트 2진 병렬 가산기 IC 품번
  - [  74LS83  ] 또는 [  74LS283  ]
