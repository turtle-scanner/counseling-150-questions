## 🏛️ [1. 임상심리 및 DSM-5-TR 감별 진단 영역]

| 시험 지문 속 결정적 힌트 표현 (발문/상황) | 0.1초 만에 튀어나와야 할 KICE 공인 만점 정답 (🟡 선명한 노란 배지) |
| :--- | :--- |
| • 빨대 호흡, 제자리 회전으로 **신체감각 인위적/고의 유발** | ➔ 👉 🟡 **【내수용성 노출 (Interoceptive Exposure)】** |
| • 심장 두근거림을 보고 **"심장마비로 죽겠구나!"** 파멸적 해석 | ➔ 👉 🟡 **【파국적 오해석 (Catastrophic Misinterpretation)】** |
| • 사람이 많은 곳이나 밀폐된 곳을 **"탈출 불가, 도움 불가"**해서 회피 | ➔ 👉 🟡 **【광장공포증 (탈출 곤란 ➕ 도움 곤란)】** |
| • 전학/이혼 등 일상 스트레스 후 **3개월 이내 발병, 6개월 이내 종료** | ➔ 👉 🟡 **【적응장애 (Adjustment Disorder)】** |
| • 외상 플래시백 패닉 상태에서 **오감(5-4-3-2-1) 자극으로 현실 복귀** | ➔ 👉 🟡 **【착지 기법 (그라운딩, Grounding)】** |
| • 검사상 이상 없으나 **실제 극심한 신체 통증에 하루 종일 몰두** | ➔ 👉 🟡 **【신체증상장애】** |
| • 신체 증상은 거의 없는데 **"암에 걸렸다"며 질병 공포로 병원 순회** | ➔ 👉 🟡 **【질병불안장애】** |
| • 대화 주고받기 위반, 농담/반어법 오해 등 **맥락/눈치 언어 결함** | ➔ 👉 🟡 **【화용론 (화용론적 언어 소통 / 실용 언어)】** |
| • 음성 틱 ➕ 운동 틱이 **동시에 1년(12개월) 이상 지속** | ➔ 👉 🟡 **【뚜렛장애 (Tourette's Disorder)】** |
| • 음성 틱 또는 운동 틱 중 **딱 한 가지만 1년 이상 지속** | ➔ 👉 🟡 **【지속성(만성) 운동 또는 음성 틱장애】** |
| • 틱 전조충동 자각 후 **틱과 양립 불가한 반대 근육 수축 수행** | ➔ 👉 🟡 **【습관반전훈련 (HRT)】** |
| • 단순 권위·규칙 반항 vs **타인의 신체·재산권 침해 및 범법 비행** | ➔ 👉 🟡 **【적대적 반항장애 (ODD) vs 품행장애 (CD)】** |
| • 문제행동을 일정 시간 동안 **'안 했을 때(0회 발생)' 보상 제공** | ➔ 👉 🟡 **【다른 행동 차별강화 (DRO)】** |
| • MMPI **SUI 척도 T $\ge$ 78점** 극단적 상승 시 조치 | ➔ 👉 🟡 **【학부모 즉각 통지 및 신변 인계 ➕ 전문병원 긴급 연계】** |
| • MMPI **THD(사고부전) 척도 T $\ge$ 80점** 이상 시 의미 | ➔ 👉 🟡 **【현실검증력 손상 (망상, 환각, 정신증)】** |
| • MMPI **EID(정서부전) ➕ RCd(침체)** 동반 상승 시 의미 | ➔ 👉 🟡 **【정서적 고통 (우울, 불안, 절망감, 의기소침)】** |
| • 웩슬러 불안/우울로 WMI·PSI 급락 시 **순수 잠재력 대체 지수** | ➔ 👉 🟡 **【일반능력지수 (GAI)】** |
| • TCI 스스로 목표 선택 및 책임 / 타인 공감 및 협력 성숙도 | ➔ 👉 🟡 **【자율성 (SD) / 연대감 (CO)】** |

## 🏛️ [2. 상담 이론 및 가족치료 영역]

| 시험 지문 속 결정적 힌트 표현 (발문/상황) | 0.1초 만에 튀어나와야 할 KICE 공인 만점 정답 (🟡 선명한 노란 배지) |
| :--- | :--- |
| • 발표 떨림 등 증상에 쏠린 **과잉주의 차단 ➔ 의미/가치로 전환** | ➔ 👉 🟡 **【탈숙고 (Dereflection)】** |
| • 싸우는 부부에게 **"매일 15분씩 일부러 더 격렬하게 싸워라"** 지시 | ➔ 👉 🟡 **【역설적 지시 (증상 처방)】** |
| • 부부 갈등에 자녀를 끌어들여 갈등을 덮는 구조를 **해체·분리** | ➔ 👉 🟡 **【탈삼각화 (상담자의 정서적 중립성 유지)】** |
| • 사고와 감정을 분리하고 정서적 융합에서 벗어난 수준 (0~100점) | ➔ 👉 🟡 **【자기분화 (Differentiation of Self)】** |
| • 비자발적으로 억지로 끌려와서 **"저 문제 없어요"** 하는 내담자 | ➔ 👉 🟡 **【방문형 내담자 (Visitor)】** |
| • **"오늘 밤 자는 사이 모든 문제가 해결되는 기적이 일어난다면?"** | ➔ 👉 🟡 **【기적 질문 (해결된 미래 상상 ➔ 희망 유발)】** |
| • 내면 감정, 상대방, 현실 상황을 **모두 온전히 존중하는 소통** | ➔ 👉 🟡 **【일치형 (자기 ➕ 타인 ➕ 상황)】** |
| • 가족 구성원의 신체 자세, 시선, 공간 배치를 **조각상처럼 배치** | ➔ 👉 🟡 **【가족조각 (무의식적 의사소통 역동 시각화)】** |
| • **"세상 친구들이 너를 반드시 좋아해야 한다는 증거가 어디 있나?"** | ➔ 👉 🟡 **【실증적 논박 (타인 당위성 해체)】** |
| • 지하철에서 시간 외치기, 짝짝이 양말 신고 걷기 등 **창피한 과제** | ➔ 👉 🟡 **【수치심 공격 연습】** |
| • **"만약 그 생각이 사실이라면, 그것이 당신에게 무엇을 의미합니까?"** | ➔ 👉 🟡 **【하향 화살표 기법 (핵심 신념 탐색)】** |
| • 타인에게 향할 분노를 자신에게 돌려 **칼로 팔목을 긋는 자해** | ➔ 👉 🟡 **【반전 (Retroflection)】** |
| • 두 개의 의자에 번갈아 앉으며 **승자(강한 나) vs 패자(약한 나) 대화** | ➔ 👉 🟡 **【빈의자 기법 (내면 양극성 대화 및 통합)】** |
| • 설리반 : 극심한 공포로 의식에서 해리된 기괴한 자아상 | ➔ 👉 🟡 **【나 아닌 나 (Not-me)】** |
| • 설리반 : 관계에 따뜻하게 개입하면서도 객관적으로 분석하는 태도 | ➔ 👉 🟡 **【참여적 관찰자 (Participant Observer)】** |

| • 무의식적 편견과 고정관념을 해체하기 위한 **비판적 반성 성찰** | ➔ 👉 🟡 **【메지로우 변혁적 학습 이론】** |
| • AI 코스웨어로 맞춤형 힌트 제공 후 **독립할 때 점진적으로 줄이기** | ➔ 👉 🟡 **【비계설정 및 점진적 철회 (Fading)】** |
| • 난이도 단계화로 작은 성공 누적 ➔ **학습 통제감 부여** | ➔ 👉 🟡 **【켈러 ARCS '자신감(C)' 전략】** |
| • 사전에 정해진 정답이 아닌 **수업 도중/종료 후 창의적 산출물** | ➔ 👉 🟡 **【아이즈너 표현적 결과 (교육적 감식안/비평)】** |
| • 교실에 고립되는 이완결합 극복을 위한 **공동 수업설계·수업나눔** | ➔ 👉 🟡 **【전문적 학습공동체 (PLC)】** |
| • 교장의 지위 권력 탈피, 도덕적 사명감으로 **교사를 섬기는 태도** | ➔ 👉 🟡 **【세르지오바니 도덕적 리더십 (서번트 리더십)】** |
