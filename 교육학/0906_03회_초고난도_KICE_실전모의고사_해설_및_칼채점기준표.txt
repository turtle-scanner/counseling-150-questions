# 2027학년도 KICE 제0906_03회 초고난도 실전모의고사 만점 모범답안 및 칼채점기준표

## 【 1교시 : 교육학 논술 만점 모범답안 및 루브릭 】 [20점]

### 1. [교육과정 영역 : 4점]
1. 3단계 역방향 교육과정 설계 모형: **위긴스와 맥타이(Wiggins & McTighe)의 백워드 설계 모형 (Understanding by Design / UbD)** [1점]
2. '영속적 이해'의 6가지 측면 중 해당 2가지: **해석(Interpretation)**, **자기인식(Self-Knowledge)** [1점]
3. 자서전적 교육과정 탐구 모형: **파이나(Pinar)의 쿠레레(Currere) 자서전적 방법 모형** [1점]
4. 제3단계 명칭: **분석(Analysis)** [1점]

### 2. [교육방법 영역 : 4점]
1. 인지적 도제 6단계 중 외면화 단계: **명료화(Articulation)** [1점]
2. 타인과 비교·검토하는 단계: **반성 / 성찰(Reflection)** [1점]
3. 작동기억 용량 고려 교수설계 이론: **스웰러(Sweller)의 인지부하이론(Cognitive Load Theory)** [1점]
4. 인지부하 명칭: 산만한 자료에 의한 부하 = **외재적 인지부하(Extraneous Cognitive Load)**, 스키마 형성에 투입되는 부하 = **본질적 인지부하(Germane Cognitive Load)** [1점]

### 3. [교육평가 영역 : 4점]
1. 수업 중 결손 파악 평가: **형성평가(Formative Evaluation)** [1점]
2. 정보 제공적 조치: **교정적 피드백(Corrective Feedback)** [1점]
3. 하위 구성요소별 세분화 기준표: **분석적 루브릭(Analytic Rubric)** [1점]
4. 핵심 장점: **과제의 세부 영역별(내용, 논리, 표현 등) 구체적인 성취 수준과 진단 정보를 제공함으로써 학생이 자신의 강점과 약점을 파악하고 목표 도달을 위한 자기조절 학습 전략을 스스로 수립·수정할 수 있도록 촉진한다.** [1점]

### 4. [교육행정 영역 : 4점]
1. 사회체제 모형: **겟젤스와 구바(Getzels & Guba)의 사회체제 모형** [1점]
2. 역할-욕구 충돌 갈등: **역할-인성 갈등(Role-Personality Conflict)** [1점]
3. 참여적 의사결정 모형: **브리지스(Bridges)의 참여적 의사결정 모형** [1점]
4. 2대 핵심 판단 기준: **관련성(Relevance)**, **전문성(Expertise)** [1점]

## 【 2교시 : 전공상담 A형 정답 및 칼채점기준표 】 [40점]

- **1번 (2점)** : ㉠ **융통성 (유연성 / Flexibility)** [1점], ㉡ **끈기 (인내 / Perseverance)** [1점]
- **2번 (2점)** : ㉠ **저항 (Resistance)** [1점], ㉡ **갈등 (지도자에 대한 도전 / 세력 싸움 / Conflict)** [1점]
- **3번 (2점)** : ㉠ **자폐스펙트럼장애 (Autism Spectrum Disorder)** [1점], ㉡ **사회적(실용적) 의사소통장애 (Social (Pragmatic) Communication Disorder)** [1점]
- **4번 (2점)** : ㉠ **페르소나 (가면 / Persona)** [1점], ㉡ **그림자 (음영 / Shadow)** [1점]
- **5번 (4점)** :
  1. 전환 명칭: **미발생 전환 (Nonevent Transition)** [2점]
  2. 4S 모형 4대 차원: **상황(Situation), 자신/자기(Self), 지지(Support), 전략(Strategies)** [1점]
  3. 전략적 개입 방안: **인지적 재구조화를 통해 상황을 긍정적으로 재해석하도록 돕거나 문제해결 중심의 단계별 실행 로드맵(재수/진학 계획)을 수립하도록 지도하여 대처 전략(Strategies)을 강화한다.** [1점]
- **6번 (4점)** :
  1. 수검 왜곡 태도: **과장 보고 (부정 왜곡 / Overreporting / Faking-Bad / 증상 과장)** [2점]
  2. 감별해야 할 가능성 2가지:
    ① **실제 중증의 정신병적 상태나 급성 정서적 위기에 처해 즉각적인 도움을 갈구하는 '도움 요청의 외침(Cry for help)'** [1점]
    ② **2차적 이득(처벌 면제, 책임 회피 등)을 위해 의도적으로 증상을 꾸며낸 꾀병(Malingering) 또는 가성 반응** [1점]
- **7번 (4점)** :
  1. 대단계 명칭: 전반부 = **예견 단계 (전의사결정 단계 / Anticipation Stage)** [1점], 후반부 = **실행 및 적응 단계 (Implementation and Adjustment Stage)** [1점]
  2. 적응 소단계: 초기 질서 수용 = **순응 (수용 / Induction)** [1점], 영향력 발휘 조직 개선 = **개혁 (Reformation)** [1점]
- **8번 (4점)** :
  1. 정식 진단명: 내담자 A = **신체증상장애 (Somatic Symptom Disorder)** [1점], 내담자 B = **질병불안장애 (Illness Anxiety Disorder)** [1점]
  2. 감별 진단 대조: **신체증상장애는 원인이 불명확하더라도 실제로 고통스러운 신체 증상이 현존하여 이에 대한 불안이 발생하는 반면, 질병불안장애는 실제 신체 증상은 없거나 매우 경미하지만 심각한 불치병에 걸렸다는 파국적 관념과 신념 자체에 압도되어 집착한다.** [2점]
- **9번 (4점)** :
  1. 3가지 논박 기법: ① **논리적 논박**, ② **경험적 논박 (실증적/사실적 논박)**, ③ **기능적 논박 (실용적/효용적 논박)** [각 1점, 총 3점]
  2. 행동적 과제 기법: **수치심 공격 연습 (수치심 극복 연습 / Shame-Attacking Exercise)** [1점]
- **10번 (4점)** :
  1. 가족구조 역동: **세대 간 연합 (세대 간 동맹 / Cross-Generational Coalition)** [2점]
  2. 치료 기법 및 작동 원리: **시련기법 (고난기법 / Ordeal Therapy)** [1점], 작동 원리는 **증상 행동을 지속하는 것보다 시련 과업을 수행하는 부담과 고통이 더 크도록 연계함으로써 내담자가 증상 행동을 스스로 포기하도록 유도하는 것이다.** [1점]
- **11번 (4점)** :
  1. 진로 문제 명칭: **자아갈등 (Intra-individual Conflict)** [2점]
  2. 심리역동적 차이점 비교: **'자아갈등'은 내담자의 내면에서 둘 이상의 상충되는 욕구, 가치, 자아 개념이 대립하여 결정을 내리지 못하는 내적 갈등인 반면, '의존성'은 내담자가 결정을 스스로 내리지 못하고 타인에게 의사결정의 주도권과 책임을 전적으로 위임하려는 자아 기능의 미성숙에서 기인한다.** [2점]
- **12번 (4점)** :
  1. 3대 핵심 역할: **교사(Teacher), 상담자(Counselor), 컨설턴트/자문가(Consultant)** [2점]
  2. 역할 매칭: **개념화 기술 = 교사 역할 (강의 및 가이드라인 직접 교육)** [1점], **개인화 기술 = 상담자 역할 (개인적 불안과 갈등 탐색 및 통찰 촉진)** [1점]

## 【 3교시 : 전공상담 B형 정답 및 칼채점기준표 】 [40점]

- **1번 (2점)** : ㉠ **해리성 기억상실증 (Dissociative Amnesia)** [1점], ㉡ **해리성 정체감 장애 (해리성 정체성 장애 / Dissociative Identity Disorder)** [1점]
- **2번 (2점)** : ㉠ **자아정체감 (정체감 / Identity)** [1점], ㉡ **정체감 유예 (모라토리엄 / Moratorium)** [1점]
- **3번 (4점)** :
  1. 가족 메커니즘: **가족투사과정 (Family Projection Process)** [1점]
  2. 세대 전수 현상: **다세대 전수과정 (Multigenerational Transmission Process)** [1점]
  3. 3단계 절차: **① 부모의 불안 (자녀에 대한 과도한 불안과 집착) ➔ ② 부모의 지각 (자녀의 행동을 문제로 규정하고 부정적 해석) ➔ ③ 부모의 처치 (자녀를 환자처럼 대우하고 과도하게 통제하여 부적응 고착화)** [2점]
- **4번 (4점)** :
  1. 정식 진단명: 내담자 A = **적대적 반항장애 (Oppositional Defiant Disorder)** [1점], 내담자 B = **품행장애 (Conduct Disorder)** [1점]
  2. 감별 진단 대조: **적대적 반항장애는 분노와 논쟁적 반항을 보이지만 타인의 기본 권리를 침해하거나 심각한 법률·규범을 위반하지 않는 반면, 품행장애는 폭행, 기물 파손, 동물 학대, 절도 등 타인의 기본 권리를 심각하게 침해하고 사회적 법률과 규범을 고의적·반복적으로 위반한다.** [2점]
- **5번 (4점)** :
  1. 생활자세 명칭: 전반부 = **자기부정-타인긍정 (I'm not OK, You're OK)** [1점], 후반부 = **자기긍정-타인부정 (I'm OK, You're not OK)** [1점]
  2. 치료적 개입 명칭: **재결단 (재결정 / Redecision)** [2점]
- **6번 (4점)** :
  1. 정식 진단명: 내담자 A = **경계선 성격장애 (Borderline Personality Disorder)** [1점], 내담자 B = **의존성 성격장애 (Dependent Personality Disorder)** [1점]
  2. 유기 불안 대처 차이점: **경계선 성격장애는 유기를 피하기 위해 분노 폭발, 이상화/평가절하, 자해 및 자살 협박 등 충동적이고 공격적인 저항 행동을 나타내는 반면, 의존성 성격장애는 유기를 피하기 위해 타인에게 맹목적으로 복종하고 비위를 맞추며 매달리는 수동적·순종적 태도를 취한다.** [1점]
  3. 치료 모델: **변증법적 행동치료 (DBT / Dialectical Behavior Therapy)** [1점]
- **7번 (4점)** :
  1. 전반부 접촉경계혼란: **융합 (Confluence)** [1점]
  2. 후반부 접촉경계혼란: **투사 (Projection)** [1점]
  3. 치료 기법: **신체자각 (신체 감각에 머무르기 / Body Awareness)** [2점]
- **8번 (4점)** :
  1. 핵심 가치 명칭: **태도가치 (Attitudinal Value)** [2점]
  2. 비극적 삼원조 3요소: **고통 (Pain / Suffering), 죄책감 (Guilt), 죽음 (Death)** [2점]
- **9번 (4점)** :
  1. 진로의사결정 유형: 학생 A = **합리적 유형 (Rational Type)** [1점], 학생 B = **직관적 유형 (Intuitive Type)** [0.5점], 학생 C = **의존적 유형 (Dependent Type)** [0.5점]
  2. 책임 귀인 차이점: **합리적 유형(학생 A)은 의사결정의 주도권을 자신이 갖고 결과에 대해 스스로 책임을 지는 내적 책임 귀인을 보이는 반면, 의존적 유형(학생 C)은 의사결정의 주도권을 타인에게 넘기고 실패나 결과에 대한 책임을 외부(부모, 교사 등)에 전가하는 외적 책임 귀인을 보인다.** [2점]
- **10번 (4점)** :
  1. 압착의 공식 명칭: 객관적 환경 자극 = **알파 압착 (Alpha Press)** [1점], 주관적 지각 환경 = **베타 압착 (Beta Press)** [1점]
  2. 투사적 회화 검사: **주제통각검사 (TAT / Thematic Apperception Test)** [2점]
- **11번 (4점)** :
  1. 가해학생 제6호 조치: 법률 명칭 = **출석정지** [1점], 출결 처리 = **미인정 결석 처리** [1점]
  2. 가해학생 제7호 및 피해학생 보호조치: 가해학생 제7호 = **학급교체** [1점], 피해학생 보호조치 = **제16조 제1항 제2호의2 학급교체** [1점]
